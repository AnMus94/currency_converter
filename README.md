# 💱 Конвертер валют (Currency Converter)

Консольное приложение на Python для конвертации валют в реальном времени. Проект разработан с соблюдением: модульной архитектуры, кэшированием данных для работы оффлайн, логированием, кастомной обработкой исключений и покрытием кода юнит-тестами. 

Особенностью разработки является активное использование ИИ-инструментов для генерации шаблонного кода, рефакторинга и написания тестов.

## Возможности

- Конвертация между любыми валютами через бесплатный API (open.er-api.com).
- **Кэширование**: сохранение курсов в JSON-файл на 1 час. Позволяет работать без интернета или при сбое API.
- **Надежность**: система кастомных исключений для обработки ошибок сети, некорректного ввода и сбоев парсинга.
- **Логирование**: запись всех операций (успешных и ошибочных) в файл `converter.log` и консоль.
- **Тестирование**: покрытие основных функций юнит-тестами с помощью `pytest` и `unittest.mock`.

## Технологический стек

- **Python 3.10+**
- `requests` – для HTTP-запросов к API
- `pytest` – для модульного тестирования
- `logging` – встроенный модуль для логирования
- **ИИ-инструменты**: Qwen, DeepSeek(для генерации исключений, рефакторинга и написания тестов)

## Запуск тестов
Для проверки работоспособности всех модулей выполните:

pytest tests/ -v

Ожидаемый результат: все тесты должны завершиться статусом PASSED.

Использование ИИ в разработке
В соответствии с требованиями итоговой работы, ИИ-инструменты применялись на следующих этапах:
Генерация исключений: Классы в exceptions.py были созданы по промпту с требованием соблюдения PEP 8, типизации и подробных docstring.
Написание тестов: Базовая структура тестов в tests/ была сгенерирована ИИ с последующей ручной доработкой моков (unittest.mock.patch).
Рефакторинг: ИИ использовался для проверки кода на соответствие стандартам и оптимизации работы с файлами кэша.
(Скриншоты промптов и диалогов с ИИ представлены в итоговом PDF-отчёте).
